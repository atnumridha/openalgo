# Automatic chart entry, SL and 2R target

User-approved scope: calculate the proposed chart plan automatically and support a real entry bought outside OpenAlgo. A user-supplied entry is the authoritative fill price, never replaced by LTP or ask. This is a read-only chart plan, not order execution or proof of a strategy edge.

Use confirmed bars only, from the selected symbol/timeframe and fixed source observation time. Compute Wilder ATR(14), causal two-left/two-right swings, and an SL beyond structure with max(one tick, 0.1 ATR) buffer and at least 1.5 ATR entry distance. Both bought CE and PE use long-premium geometry. BTC/index long and short geometry are separate. Tick-aligned entries and outward-rounded SL imply an exactly tick-aligned 2R target. Reject invalid/nonpositive/off-tick entries, absent ATR/structure, nonpositive target and stale/wrong/replay scope; never fabricate a level. Existing positions can have already crossed proposed levels: label this explicitly, do not move the entry or quietly widen a frozen stop.

Automatic entry mode uses a confirmed breakout/retest, waits up to three subsequent bars for a retest close, triggers one tick beyond the retest extreme, and expires an unfilled entry after two bars. Prefer 15-minute confirmed structural bias when aggregatable from complete source bars; otherwise label automatic setup unavailable rather than substituting an unapproved filter. Bought CE requires bullish underlying bias and bought PE bearish underlying bias; premium entries remain long. Fetch one deduplicated underlying 15m history per selected option where needed, not per price tick. Outside-entry mode does not require a new entry signal or trend permission because the position already exists.

Freeze an applied outside-entry plan until Apply/Recalculate is used. A new symbol, timeframe, user or app mode clears it; never leak to replay or another contract. The UI shows entry, SL, target, risk distance, stop source and status in the existing chart tool dock without changing chart height. Existing option fee estimation is reused and remains separately estimated. BTC/index price calculations must not reuse option lot sizes, rupee fees or option risk geometry. Missing risk budget is shown as unset; no account sizing or safety enforcement is claimed.

Approach: a pure local math/setup module, one chart planner component using existing dock/buttons/input components, and a small integration into NeoMarketChart. Keep the previous manual calculator reusable as the embedded option fee calculator. All raw quotes continue to alerts; plan calculations run on verified history changes and explicit user actions, not each tick.


Universal chart extension authorized by the user's subsequent instructions: expose symbol search and indicator controls across supported broker instruments and BTCUSD/ETHUSD. Keep options-only data unavailable when its required contract/chain is absent. For commodity/currency options with no verified cash underlying, explicitly label and use own-premium 15-minute trend; both bought CE and PE require bullish premium confirmation. The original CE/PE underlying-bias rule remains for verified equity/index underlyings.

Crypto extension: use continuous UTC source candles and UTC days for daily research windows. All price-direction displays read LONG/SHORT; price-based studies, structural levels and trade plans share that direction. Exact gross target distance is2×entry-to-SL distance, with contract tick alignment; fees remain separate. Genuine Delta open-interest candles may supply matched completed-candle context; IV/PCR require option contracts/chains and remain inapplicable to perpetuals. No automated order strategy is enabled or altered.
