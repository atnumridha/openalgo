# TradingView workspace, strategy readiness and saved sessions — 14 October 2026

The native `/trading` route uses genuine TradingView Lightweight Charts 5.1 for the Neo deployment. Other OpenAlgo deployments retain the existing workspace. Kotak supplies historical and real-time prices; this is not the hosted Advanced Charts product and it does not execute Pine. The shared scalping chart wrapper uses the same renderer.

The chart shows NIFTY or a selected CE/PE contract, defaults to the nearest active expiry, lists expiries newest first, and exposes separate ascending strike lists with ATM/ITM/OTM classifications. Supported views are 1m, 3m, 5m, 15m, 30m, 1h and daily. Unsupported chart choices no longer silently become 1m. Daily data maps to Kotak's D interval. The default viewport is 90 candles; IST axes and crosshair readouts normalize the broker display offset exactly once.

BUY/SL/target lines come from native confirmed owned fills and use the exact matching instrument's scale. Fresh websocket bars update immediately; historical reconciliation preserves a newer websocket bar and does not invent overnight candles. Empty option selections wait for a contract instead of making invalid broker requests.
