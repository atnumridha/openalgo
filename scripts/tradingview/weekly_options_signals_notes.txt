ONE AT A TIME
Use a standard NSE:NIFTY chart, 1-minute interval. Each file is an independent
indicator. Test one, remove that temporary chart instance, then test the other.
Keep the source files locally if the TradingView account limits saved scripts.
Enabling only one chart indicator does not necessarily change the account's
separate saved-script limit. Do not overwrite an unrelated saved script.

SIGNALS
Green ENTER / HOLD: the configured cycle qualified at the confirmed entry close.
Red EXIT: the tested premium-stop condition has triggered.
Yellow WAIT / NO ENTRY / REVIEW: no valid entry, wrong chart, missing quotes,
or a required stop observation could not be evaluated.
Blue expiry label: the selected expiry was reached; use official cash settlement.
Each entry label specifies all legs. These are option-selling combinations,
not directional BUY CALL / BUY PUT signals. The strangle is unhedged.

DATA AND EXECUTION
Only exact-minute quotes qualify; entry legs must have positive traded volume.
An unavailable symbol returns missing data rather than crashing the indicator.
Missing entry data gives NO ENTRY. It never inserts a late replacement entry.
A missing required stop observation gives REVIEW - DATA GAP. The script cannot
infer whether a stop would have filled during that gap.
The strike banks keep the number of requested symbols within TradingView's
request limits. Adjust bank centres if a required contract is outside the bank.

The credit shown is a signal-minute close reference. It is not a broker fill.
An optional Actual filled net credit input can set the stop reference for an
already executed combination. This does not create or validate any fill.
The historical research used next-minute-open execution and trading costs;
these indicators do not calculate that backtest P&L or promise its win rate.
Expiry labels do not treat last-traded option premiums as official settlement.
Alerts are signals only. Neither file submits orders or manages broker positions.
